# RealWorldUX Design System

## Overview

**Tagline:** Practical, delightful and innovative

**Mission:** RealWorldUX solves user problems in a practical way while still providing delightful and innovative experience

**Brand personality:** Clean, to the point.

**Tone of voice:** Professional, concise.

This is a **light** theme design system.

## Brand Identity

The brand name is **RealWorldUX**. Use it as the site title and in navigation unless the project specifies otherwise.

- **Logo:** `/static/design-system-customer/c90c23a0-a9f6-4787-a6ae-396bf634286d/f10c3f6b-f6b0-4697-945b-8d6d1273db7a/1d979043-ca4f-4a2e-92c8-2d9bc5058604/original_repo/public/image/RealWorldUX_logo_blue.svg`
- **Favicon:** `/static/design-system-customer/c90c23a0-a9f6-4787-a6ae-396bf634286d/f10c3f6b-f6b0-4697-945b-8d6d1273db7a/1d979043-ca4f-4a2e-92c8-2d9bc5058604/original_repo/public/image/favicon.ico`

Place the logo in the app bar or header. Ensure sufficient contrast against the background.

## Colors

- **Primary:** `#0071bc` — the main brand accent color used for interactive elements, links, and key UI highlights.
- **Background:** `rgb(255, 255, 255)` — the base page surface color.
- **Foreground:** `rgb(40, 40, 40)` — the default text color for body copy.
- **Secondary:** `rgba(52, 173, 163, 0.8)` — supporting accent for secondary actions.
- **Border/Outline:** `rgba(180, 180, 180, 0.35)` — used for dividers and input borders.
- **Muted surface:** `rgb(255, 255, 255)` — subdued backgrounds for cards or secondary areas.
- **Muted text:** `rgb(40, 40, 40)` — secondary/placeholder text color.

## Typography

The primary typeface is **"Asap Condensed", sans-serif**.

Monospace: `ui-monospace, monospace`.

**Type scale:**

- **body-md:** 16px, weight 400
- **headline-lg:** 1.5rem, weight 600
- **display-lg:** clamp(1.75rem, 5vw, 2.75rem), weight 700
- **label-sm:** 12px, weight 600

## Layout

- **Base spacing unit:** `4rem` — all dimensions use multiples of this value.
- **Content max width:** `900px`
- **App bar position:** sticky

## Shapes

- **Default corner radius:** `8px` — applied to cards, inputs, and containers.
- **Full radius:** `9999px` — used for pills, avatars, and circular elements.
- **Button shape:** pill
- **Full-radius semantics:** pill for chips

## Components

- **Navigation active state:** underline
- **Card hover effect:** border
- **Primary button shape:** pill

## Do's and Don'ts

**Do:**
- Use the defined color tokens instead of hardcoded hex values
- Follow the type scale hierarchy for consistent visual weight
- Maintain the spacing rhythm using the base unit multiples
- Use semantic color roles (primary, background, foreground) for themeable UIs

**Don't:**
- Introduce new colors outside the defined palette
- Mix font families beyond the defined base and mono stacks
- Use arbitrary border radius values — stick to the rounded scale
- Override component conventions without updating the design system
