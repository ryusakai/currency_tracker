# Material Design System

## Overview

**Brand personality:** Confident.

**Tone of voice:** Friendly.

This is a **light** theme design system.

## Brand Identity

The brand name is **Material**. Use it as the site title and in navigation unless the project specifies otherwise.

- **Logo:** `/static/design-system-customer/c90c23a0-a9f6-4787-a6ae-396bf634286d/96153a02-d413-464b-a514-f16c17506c09/f13d7251-590b-4379-ac81-1c1b9f4dfef5/original_repo/material%203%20logo.png`
- **Favicon:** `/static/design-system-customer/c90c23a0-a9f6-4787-a6ae-396bf634286d/96153a02-d413-464b-a514-f16c17506c09/f13d7251-590b-4379-ac81-1c1b9f4dfef5/original_repo/favicon.ico`

Place the logo in the app bar or header. Ensure sufficient contrast against the background.

## Colors

- **Primary:** `#b3261e` — the main brand accent color used for interactive elements, links, and key UI highlights.
- **Background:** `#fff` — the base page surface color.
- **Foreground:** `#000` — the default text color for body copy.
- **Secondary:** `#6750a4` — supporting accent for secondary actions.
- **Border/Outline:** `#cac4d0` — used for dividers and input borders.
- **Muted surface:** `#fff` — subdued backgrounds for cards or secondary areas.
- **Muted text:** `#000` — secondary/placeholder text color.

## Typography

The primary typeface is **ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace**.

Monospace: `ui-monospace, monospace`.

**Type scale:**

- **body-md:** 16px, weight 400
- **headline-lg:** 1.5rem, weight 600
- **display-lg:** clamp(1.75rem, 5vw, 2.75rem), weight 700
- **label-sm:** 12px, weight 600

## Layout

- **Base spacing unit:** `18px` — all dimensions use multiples of this value.
- **Content max width:** `740px`
- **App bar position:** sticky

## Shapes

- **Default corner radius:** `100px` — applied to cards, inputs, and containers.
- **Full radius:** `100px` — used for pills, avatars, and circular elements.
- **Button shape:** pill

## Components

- **Navigation active state:** underline-thick
- **Card hover effect:** elevation
- **Primary button shape:** pill

## Do's and Don'ts

**Do:**
- Use the defined color tokens instead of hardcoded hex values
- Follow the type scale hierarchy for consistent visual weight
- Maintain the spacing rhythm using the base unit multiples
- Use semantic color roles (primary, background, foreground) for themeable UIs

**Don't:**
- Introduce new colors outside the defined palette
- Mix font families beyond the defined base and mono stacks
- Use arbitrary border radius values — stick to the rounded scale
- Override component conventions without updating the design system
