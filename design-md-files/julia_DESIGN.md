# julia Design System

## Overview

**Brand personality:** Calm, soft.

**Tone of voice:** Soft, clean.

This is a **light** theme design system.

## Brand Identity

The brand name is **julia**. Use it as the site title and in navigation unless the project specifies otherwise.

- **Logo:** `/static/design-system-customer/c90c23a0-a9f6-4787-a6ae-396bf634286d/6c0a564a-42cd-4108-bb37-381e710387fe/574e5741-35b8-4496-80d6-b8436f38184e/original_repo/assets/images/logo-dark.svg`
- **Favicon:** `/static/design-system-customer/c90c23a0-a9f6-4787-a6ae-396bf634286d/6c0a564a-42cd-4108-bb37-381e710387fe/574e5741-35b8-4496-80d6-b8436f38184e/original_repo/favicon.svg`

Place the logo in the app bar or header. Ensure sufficient contrast against the background.

## Colors

- **Primary:** `#d16b86` — the main brand accent color used for interactive elements, links, and key UI highlights.
- **Background:** `#fcf4f6` — the base page surface color.
- **Foreground:** `#111827` — the default text color for body copy.
- **Muted surface:** `#fcf4f6` — subdued backgrounds for cards or secondary areas.
- **Muted text:** `#6b7280` — secondary/placeholder text color.

## Typography

The primary typeface is **'Manrope', sans-serif**.

Monospace: `ui-monospace, monospace`.

**Type scale:**

- **body-md:** 16px, weight 400
- **headline-lg:** 1.5rem, weight 600
- **display-lg:** clamp(1.75rem, 5vw, 2.75rem), weight 700
- **label-sm:** 12px, weight 600

## Layout

- **Base spacing unit:** `32px` — all dimensions use multiples of this value.
- **Content max width:** `740px`
- **App bar position:** sticky

## Shapes

- **Default corner radius:** `100px` — applied to cards, inputs, and containers.
- **Full radius:** `100px` — used for pills, avatars, and circular elements.
- **Button shape:** pill

## Components

- **Navigation active state:** highlight
- **Card hover effect:** elevation
- **Primary button shape:** pill

## Do's and Don'ts

**Do:**
- Use the defined color tokens instead of hardcoded hex values
- Follow the type scale hierarchy for consistent visual weight
- Maintain the spacing rhythm using the base unit multiples
- Use semantic color roles (primary, background, foreground) for themeable UIs

**Don't:**
- Introduce new colors outside the defined palette
- Mix font families beyond the defined base and mono stacks
- Use arbitrary border radius values — stick to the rounded scale
- Override component conventions without updating the design system
